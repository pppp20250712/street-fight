CONTROLS操作方式

按住「遠離對手」的方向即可防禦；掃腿屬下段攻擊，必須蹲著防禦；跳躍攻擊屬上段，必須站著防禦。Hold away from the opponent to block. Sweeps are low (crouch-block); jump attacks are overheads (stand-block).

BUILD & RUN建置與執行

需要 Android Studio（含 Android SDK 37）。最低支援 Android 14（API 34）。Requires Android Studio with Android SDK 37. Minimum Android 14 (API 34).

  1. 下載專案 Clone
    git clone https://github.com/pppp20250712/street-fight.git
  2. 開啟 Open — Android Studio → File → Open → 選擇專案資料夾。Choose the project folder.
  3. 同步 Sync — 按 Sync Project with Gradle Files，等待下載完成。Wait for Gradle sync to finish.
  4. 執行 Run — 選擇模擬器或連接手機，Run 設定選 app，按 ▶。Pick an emulator or device, select the app configuration, press ▶.

SOURCE CODE程式架構

全部遊戲程式位於 app/src/main/java/streetfight/，套件名稱 com.example.myapplication20261102streetfighter.game。All game code lives in app/src/main/java/streetfight/.

檔案 File內容 Purpose
FightActivity.kt啟動畫面、全螢幕、暫停／恢復。Launcher activity, fullscreen, pause/resume.
GameView.kt60 FPS 遊戲迴圈、場景、回合流程、碰撞判定、HUD、觸控與鍵盤。60 FPS loop, scenes, round flow, hit detection, HUD, touch & keys.
Fighter.kt角色狀態機（走、跳、蹲、攻擊、防禦、受擊、倒地）與物理。Fighter state machine and physics.
Data.kt姿勢、骨架、招式數值、角色設定。Poses, skeleton, move frame data, fighter styles.
Renderer3D.ktOpenGL ES 3 繪製器：陰影貼圖、燈光、角色 3D 模型組裝、特效與 HUD 底下的整個場景。OpenGL ES 3 renderer: shadow map, lighting, 3D fighter rig, effects and the whole street scene.
Gfx.kt矩陣運算、旋轉體／方塊幾何、跟隨攝影機。Matrix math, lathe / box geometry, follow camera.
StageTex.kt程式產生的柏油路、建築立面、天空、霓虹招牌與光暈貼圖。Procedural asphalt, facades, sky, neon-sign and glow textures.
AI.kt電腦對手的決策與反應。CPU opponent decisions and reactions.
Sfx.kt合成 WAV 音效並以 SoundPool 播放。Synthesized WAV effects played with SoundPool.
docs/play/網頁 3D 版（WebGL2），與 Android 版同一套規則與著色器。Browser 3D version (WebGL2) with the same rules and shaders.

遊戲邏輯仍在固定的 384 × 216 平面上運算（1 單位 = 1/30 公尺）；角色由 12 個關節角度組成的姿勢驅動，3D 模型直接套在同一副骨架上，所以攻擊判定點仍是拳頭或腳尖的位置。Game logic still runs on a fixed 384 × 216 plane (1 unit = 1/30 m). Fighters are driven by 12-angle poses and the 3D models are built on that same skeleton, so each hitbox still sits on the actual fist or foot.
